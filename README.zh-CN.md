# Kil 地下水：开采强度与河流交换的关系

**通过 GMS / MODFLOW 稳态模型，比较瑞典 Örebro 附近冰水沉积含水层的 10 与 20 L/s 开采情景。**

## 研究问题

地下水开采量翻倍后，新增抽水由水量平衡中的哪些部分补偿？本案例从地质概念模型出发，结合渗透系数分区、水头对比和开采情景，分析抽水对地下水向河流排泄的影响。

## 输入与参数

| 项目 | 设置 |
|---|---|
| 模型 | GMS / MODFLOW，稳态计算 |
| 研究区 | Örebro 附近 Kil 冰水沉积含水层；采用 SGU 地质资料 |
| 网格 | 20 × 20 m |
| 底板高程 | 30 m |
| 六个渗透系数分区 | 15、20、30、46、100、120 m/日 |
| 面补给 | (0.65 − 0.40) × 0.75 / 365 ≈ 0.000514 m/日 |
| 河流水位 / 河床高程 | 43.9 / 42.9 m；44.0 / 43.0 m |
| 排水边界 | 高程 48 m，导水系数 50 m²/日 |
| 开采情景 | 10 L/s = 864 m³/日；20 L/s = 1,728 m³/日 |

![渗透系数分区](figures/conductivity-zones.png)

## 水量平衡与判断

下表为原分析报告中的流量大小：补给为流入，抽水、排水边界与地下水向河流的净排泄为流出。

| 分量，m³/日 | 10 L/s | 20 L/s |
|---|---:|---:|
| 面补给 | 3,035.24 | 3,035.24 |
| 抽水 | 864.00 | 1,728.00 |
| 排水边界流出 | 396.81 | 387.21 |
| 地下水向河流排泄 | 1,774.42 | 920.01 |

开采量翻倍后，模型中地下水向河流的排泄减少 **854.41 m³/日，约 48%**。新增抽水主要由向河流排泄量的减少补偿。这一比例指地下水模型中的河流交换分量，不代表整条河流的流量减少了 48%。

![模拟水头与观测值的比较](figures/head-comparison.png)

建模过程包含水头对比与地形表达调整。已有水头偏差需要结合情景结果一起理解；稳态水量平衡用于比较开采影响，不能单独据此确定长期可持续开采量。
